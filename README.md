One original fortune-cookie line for a software developer, written in the
voice of a real fortune cookie and aimed squarely at the tired senior
engineer who has inherited one too many codebases: *"You will inherit code
written by a stranger who signs his work with your name."* It is true about
a developer's day — sooner or later everyone opens a file they do not
recognise, only to find their own name in the blame — and its quiet twist is
that the stranger is past you, so the warning lands twice: once about the
code you are about to read, and once about the code you are about to write.
`main.py` (pure Python standard library) writes exactly that single line to
`/output/entry.txt`, failing fast if it ever exceeds the 120-character limit.
